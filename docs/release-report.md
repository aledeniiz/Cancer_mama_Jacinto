# Informe de entrega científica ampliada

Se amplió la edición inicial de código y resultados agregados para incluir los
recursos conservados necesarios para revisar el trabajo: 17 modelos, transformadores,
metadatos públicos, particiones, embeddings, predicciones OOF/TEST y fuentes históricas
con su procedencia. Se incluye la presentación ejecutiva final en PPTX/PDF.

Los archivos se verificaron antes de publicar. No se añadieron MRI, validación
privada del profesor, secretos, entornos, respaldos ni extracciones inválidas.
No hubo entrenamiento ni cambios de arquitectura, pesos o resultados originales.
Véanse [verificación](verification.md) y [evaluación docente](../EVALUACION_PROFESOR.md).

Persisten tres límites: las MRI son necesarias para repetir el encoder desde
píxeles; no existe estimador guardado de fusión lineal ni clínico final global;
GitHub Pages es estático y no satisface por sí solo la prueba docente de inferencia
sobre pacientes nuevos. Se documentan sin inventar recursos o resultados.

La web conserva el diseño existente y las métricas científicas. El repositorio
conserva su historial y los originales y respaldos locales permanecen intactos.
Las licencias de código, datos y elementos institucionales se distinguen en
[redistribución](redistribution.md) y [NOTICE](../NOTICE.md).
